cube 模数网格

着色器按世界坐标画，不改几何、不加面、不需要 UV。 wall 和 floor 不画（那两样是建筑面，不是家具模块）。模数已按你的 300 mm 设好；三个「相位」是把格线整体挪半格以内，用来和 cube 的实际面对齐。

家具（家属版预览原型）

按图层名把家具拆出来，每件一张卡片。缩略图是实时渲染的 —— 不是预先烘好的图片，所以换材质时它和右边的 3D 预览会一起变。
下面那排色块是我从材质库自动挑的示意选项，不是最终方案； 等你定好每件家具给几个选项、分别是什么，我再换成真的。

材质分组（按图层名）

左边是分到的组，右边是件数，分组完全按 Rhino 图层名。 每组都有自己的 颜色 / 粗糙度 / 法线 三张贴图， 全部是打开页面时现场算的，不下载任何图片文件 —— 户型会换，贴图文件的尺寸一旦对不上就会被拉伸，程序化的图按 「世界坐标 ÷ 实际米数」贴，1 米永远是 1 米。
右边的色块是在贴图上叠加染色，不是替换颜色，调过头会脏。 分错的告诉我图层名，我改映射表，模型不用动。

已读到的真实贴图：（无）　 把图放到 assets/tex/<组名>/ 下，命名 color.jpg / normal.jpg / rough.jpg / ao.jpg，刷新即生效； 没放的组继续用程序化贴图。

方案（配色版本）

调好一版就点「导出」，把框里那段 JSON 发给我，我记进方案表。 别用手抄 —— 24 个图层的材质 id 加上全局参数，抄一遍必错。
「载入」是把之前导出的 JSON 贴回来，用来在几版之间来回对比。

轮廓线

用 EdgesGeometry 现算，不占文件。 13 万面全算一遍要几秒，所以默认关着 —— 需要再开。

光 · 阴影 · 遮蔽

这一段比任何一张贴图都重要。所谓"廉价感"的根源 不是材质不够花哨，是缝隙里不够暗 —— 现实里两块板 贴在一起，环境光进不去，交界处会自然形成一圈暗影；没有这圈暗影， 再好的木纹也像贴纸糊上去的。
遮蔽＝屏幕空间 AO（现算，不烘焙）； 阴影软度＝ VSM 阴影的模糊半径，就是参考图里那种边缘会 随距离变宽的软阴影。

整体

环境贴图是材质好不好看的第一位因素。PBR 材质的 高光和反射全部来自它 —— 环境里只有一片均匀的灰，金属和釉面反射到的 也只有一片均匀的灰，所有材质就被拉平成一个样子。
摄影棚＝ three.js 官方例子 webgl_loader_gltf 用的那个 RoomEnvironment，六片亮度差五倍的发光板 + 六个反弹箱子； 住宅窗光＝我按"一侧有窗的居室"手调的，偏暖、方向性更强。
